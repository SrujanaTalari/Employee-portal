# 💼 Employee Portal System

> A clean and responsive employee management portal designed for secure login access and personalized employee dashboards.

---

## ✨ About The Project

The **Employee Portal System** is a modern web application developed using **HTML, CSS, JavaScript, Node.js, Express.js, and MySQL**.  

This project allows employees to securely log in and access their personal dashboard containing employee information such as department, email, phone number, and address.

The system also tracks employee login activity and provides a smooth user experience with session handling using local storage.

---

## 🚀 Features

✨ Secure Employee Login  
✨ Personalized Dashboard  
✨ Employee Information Display  
✨ Login Activity Tracking  
✨ Local Storage Session Management  
✨ Responsive & Minimal UI
